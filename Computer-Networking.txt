- Network Topologies : Its a arrangement of computer networks.
- Bus Topologies : All devices are connected to a single cable, less complex and less expensive but single point of failure.
- Star Topologies : One Center Hub all devices are connected to it like star. Example LAN. Easy to install new device and remove. but single point of failure.
- Ring Topologies : devices are connected like a ring. enclosed in a circular way. bandwith high and low fault tolerence but adding or removing devices will be difficult. 
- Mesh Topologies : All devices are connected to each other. Example Military Telecommunication. Highly Reliable and hight fault tolerence its expencive and difficult to manage.
- Tree Topologies : Devices are assembled like a tree. It maintains a client server network. Easy to expand. Like a branch mirpur are need a new user connection.

- In OSI Model there are 7 layers. 1. Physical Layer, 2. Data Layer, 3. Network Layer, 4. Transport Layer. 5. Session Layer, 6. Presentation Layer, 7. Application Layer. (Please Do Not Throw Sausags Pizas Away).
- Scenario : Linus sends "hi" from this phone, tovey receives it on her phone. 
- Application: WhatsApp app — user composes message (PDU: Data).
- Presentation: Encodes/compresses/encrypts message (e.g., Signal protocol) (PDU: Data).
- Session: Manages session/connection context between endpoints (PDU: Data).
- Transport: Adds TCP/UDP header (ports, seq/ACK) — makes transfer reliable if TCP (PDU: Segment/Datagram).
- Network: Adds IP header (source/destination IP) for routing (PDU: Packet).
- Data Link: Adds MAC header & trailer (Ethernet frame: src/dst MAC, FCS) for local delivery (PDU: Frame).
- Physical: Sends raw bits over cable/wireless (PDU: Bits).
- Encryption : Symmetric (both end use same key) and asymmetric (both end use different key. example : public and private).
