- iptables -A INPUT -j DROP (drops all the request)

- here the incoming request works like this. the request comes, it checks the ip tables rules from top to bottom, to check wheater this request is allowed or not. if it finds a match first time it does not check for anyting below. so in the drop rules since its meant for all kind of request it will block any request)

- iptables -A OUTPUT -p tcp -d 172.16.238.11 --dport 5432 -j ACCEPT (adding the outbound rules for postgray sql, similar as inbound)
