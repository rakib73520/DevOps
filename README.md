## 🗺️ What Is This Repo?

This is my **personal DevOps knowledge base** — a growing collection of step-by-step guides, commands, configs, and explanations for every tool and concept I learn. Written clearly enough that **future me** (or anyone else) can pick it up and understand it instantly.

Think of it as a living textbook — updated every time I learn something new.

---

## 📂 Repository Structure

```
📦 DevOps/
 ┣ 📁 Linux/          → Commands, file system, permissions, shell scripting
 ┣ 📁 Git/            → Version control workflows, branching, rebasing
 ┣ 📁 Docker/         → Containers, images, Dockerfiles, Compose
 ┣ 📁 Networking/     → TCP/IP, DNS, HTTP, firewalls, ports
 ┣ 📁 Aws/            → EC2, S3, IAM, VPC, and cloud fundamentals
 ┗ 📁 Notes/          → Miscellaneous notes, cheatsheets, quick refs
```

## 📖 How This Repo Is Organized

Every folder follows the same structure — each topic has its own markdown file or folder with:

- 📝 **Concept explanation** — what it is and why it matters
- ⚙️ **Step-by-step setup** — exact commands to run, configs to write
- 💡 **Real examples** — practical use cases, not just theory
- ⚠️ **Gotchas & tips** — things I actually struggled with
- 🔗 **References** — useful links and further reading

This makes it a **reference guide I can return to** — not just notes I wrote and forgot.
